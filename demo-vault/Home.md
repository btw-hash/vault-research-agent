# Nimbus Labs — Vault Home

This is the team vault for **Nimbus Labs**, a small studio building developer and
productivity tools. It's a fictional company, built as demo content for the
`vault-research-agent` project — everything below (products, people, decisions) is
invented.

## Products

- [[Aurora Notebook]] — the flagship AI-powered notebook app (prosumer)
- [[Beacon CLI]] — command-line tool for managing cloud deployments
- [[Constellation Sync]] — the sync engine behind Aurora Notebook
- [[Fleet Dashboard]] — internal ops dashboard for service health
- [[Waypoint Bot]] — Telegram bot for reminders and session logging
- [[Nimbus Agents Kit (OSS)]] — open-source pack of agent configs the team publishes

## Tools & Integrations

- Claude Code for pair-programming across all repos
- An internal analytics MCP server exposes Fleet Dashboard metrics as tools/resources
  (see [[Architecture Decisions]] ADR-3, and the [[Session History]] entry for how it
  was wired up)
- [[Team Bots]] lists the chat bots the team runs day to day

## Logs & Notes

- [[Session History]] — chronological log of integration and infra work
- [[Weekly Log]] — weekly summaries per project
- `daily/` — day-by-day working notes, one file per day
- [[Style Guide]] — how the team writes notes and closes out a work session
